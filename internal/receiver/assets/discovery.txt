# Bridge Health

> Public health reports from enrolled pillar operators running Zenon mainnet bridge orchestrators.

Fetch a current snapshot when answering status questions. Each row represents one enrolled pillar. Report the snapshot timestamp and use the last heartbeat receipt time when describing an individual pillar.

Online means the latest heartbeat was fresh and the local snapshot read succeeded. Unavailable means the reporter checked in but the read failed. Stale means three minutes or more have elapsed since the last heartbeat. Awaiting report means an enrolled reporter has yet to send its first heartbeat.

BNB (BNB Smart Chain) and ETH (Ethereum) counts show observed unsigned wraps and unwraps for each pillar. Several pillars can observe the same work. Preserve partial counts and unknown values when quoting them. The JSON provides the quality and observation time of each count.
